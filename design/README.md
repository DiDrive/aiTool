# AigcPanel UI 设计文件索引

## 正式落地方向

优先使用以下三份：

- `aigcpanel-refined-ui-kit.html`
  - 当前最新精修稿。
  - 去掉“模型市场 / 工单反馈 / 问题反馈”。
  - 在不改变现有功能模式的前提下，提升质感、可读性和易用性。

- `aigcpanel-conservative-ui-guidelines.md`
  - 保守改版准则。
  - 明确保留现有功能模式、页面结构和业务边界。

- `aigcpanel-conservative-ui-kit.html`
  - 保守版 UI Kit，作为结构参考。
  - 包含共用部件、首页、模型页、视频页，以及声音/工具/直播/设置的现有 tab 模式整理。

## 参考探索稿

- `aigcpanel-full-ui-kit.html`
