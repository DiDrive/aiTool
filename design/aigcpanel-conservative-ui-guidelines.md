# AigcPanel 保守改版设计准则

## 核心原则

这次 UI 改版应基于现有功能模式，不重组业务流程，不改变用户已经熟悉的页面入口。

- 保留现有主导航形态，但调整分类：`首页 / 数字人 / 模型 / 视频 / 声音 / 生图 / 设置`。
- 保留现有二级导航：视频、声音、生图、数字人、设置页继续使用左侧 tab 切换。
- 保留现有任务提交模式：页面内填写参数，点击提交后进入右侧任务结果栏。
- 保留现有云任务侧栏逻辑：只优化命名、视觉层级、筛选和结果卡片，不改变数据来源。
- 保留现有 Arco 组件和 Tailwind/LESS 体系，避免一次性引入全新的 UI 框架。

## 改版边界

### 可以改

- 卡片、按钮、输入框、列表、表格、空状态的视觉统一。
- 页面标题区、说明文案、操作按钮的布局。
- 二级导航的选中态、间距、图标和可读性。
- 右侧任务结果栏的视觉结构、折叠态、筛选区和任务卡片。
- 首页功能入口卡片的层级和统计模块的可读性。
- 表单页的分区标题、参数布局、预览区域和提交按钮位置。

### 不应改

- 不把所有能力合并成新的“创作流程”强制入口。
- 不取消视频/声音/生图/数字人页现有 tab 模式。
- 不把模型页改成完全不同的信息架构。
- 不改变任务数据、服务数据、云模板数据的业务逻辑。
- 不把右侧任务结果栏变成只属于首页的模块。

## 各页面应如何设计

### 首页

保持现有首页定位：功能入口 + 数据统计 + 常用能力集合。

优化方向：
- 顶部欢迎区更紧凑。
- 四个核心入口继续保留：声音合成、声音克隆/识别、视频合成、数字人直播。
- 数据统计继续展示生成次数和今日增量。
- 常用能力集合继续从应用分组渲染，只优化卡片样式和分类展示。

### 模型页

保持现有模型服务管理模式。

优化方向：
- 顶部按钮保留：模型与平台、添加远程、添加本地。
- 服务卡片保留状态、能力标签、日志、删除、信息、设置、启动/停止。
- 空状态保留添加本地/远程和帮助入口。

### 视频页

视频页只放“生视频”相关能力，不再放数字人、口型、直播片段和一键合成。

二级项包括：
- 云端生视频
- Seedance 2.0

优化方向：
- 左侧 tab 更清晰。
- 右侧动态组件区域保持原逻辑。
- 内部表单只做视觉分区，不改变参数字段。

### 声音页

保持现有 `SoundApps` 二级导航。

二级项包括：
- 云端生音频
- 云端克隆音色

优化方向：
- 强化音频任务提交区、音色选择区、结果预览区。
- 不新增不存在的本地声音工作室流程。

### 生图页

原“工具”改名为“生图”，只放图片生成相关能力。

二级项包括：
- GPT Image 2
- 云端生图

优化方向：
- 每个生图工具页仍是独立能力页。
- 支持从右侧任务结果栏复用产物，但不强制流程化。

### 数字人页

数字人栏目承载数字人、口型、直播片段和直播编排相关能力。

二级项包括：
- 云端对口型
- 云端普通数字人
- 数字人直播片段
- 直播执行配置
- 数字人直播编排
- 直播知识库
- 直播控制台
- 直播互动
- 播报历史

优化方向：
- 二级导航视觉统一。
- 每个 tab 内部继续承载原组件。
- 直播控制台可以增强状态展示，但不改变原有操作入口。

### 设置页

保持现有滚动锚点模式：
- 基础设置
- 数据配置
- 数字人资产
- 环境
- 关于软件

优化方向：
- 左侧锚点菜单视觉统一。
- 内容区域用 `SettingRow` 风格组织。
- 保留现有配置弹窗按钮。

## 右侧任务结果栏命名

建议命名为“任务结果”，与当前代码一致；如果需要强调排期，可在副标题中写：

> 云端任务排期、运行状态与产出结果

不要改成只叫“排期”，否则会弱化已经完成任务的结果查看功能。
