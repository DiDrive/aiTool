# 无限画布接入背景

目标是在唯变 AI 工作台中使用 `tigerowo/infinite-canvas`，优先完成 Windows
桌面端。上游是 Next.js + Go + SQLite 的完整应用，并使用 AGPL-3.0；工作台本身
不是 React/Next 技术栈，因此不把源码混入 Vue 渲染进程，而把它作为独立本地服务
管理和打开。

本阶段交付接入层：工作台入口、外部服务模式、本地 sidecar 生命周期、健康检查、
独立安全窗口和运行包规范。上游运行包需要单独构建并携带对应源码后，才可用于发布。

创作流程目标为“创意/剧本 → 镜头拆解 → 角色与场景参考 → 分镜图 → 视频”。上游
画布 Agent 已具备对应节点工具和阶段规则，本项目负责把工作台已启用的文本、图片、
视频模型按各自渠道同步给画布，不在 Vue 侧重复实现一套创作引擎。

视频倒推升级目标不是摘要，而是建立可编辑的原片证据时间轴。上传视频支持非破坏裁剪
和独立分析区间；分析结果必须保留绝对/相对时间、人物、场景、风格、动作、台词与证据，
并允许叠加用户上传的剧情梗概生成独立改编分支。原片解析数据不得被改编覆盖。
