# 审查清单

- sidecar 只监听 `127.0.0.1`，API 不暴露到局域网
- 端口冲突时自动选择可用端口
- 本地管理员密码和 JWT secret 非默认值且不进入日志/仓库
- 画布窗口 `nodeIntegration=false`、`contextIsolation=true`、`sandbox=true`
- 页面导航和权限请求不能逃逸到工作台权限域
- API 或 Web 启动失败时清理已创建的子进程
- 退出工作台时清理进程，数据和日志保留
- external URL 只接受 HTTP/HTTPS，健康检查失败有清晰提示
- 发布物包含固定上游 commit 的完整对应源码、AGPL LICENSE 和修改说明
- 安装、升级、卸载后数据策略符合产品预期
- 手动创建与 Agent 创建的创作节点使用同一 `workflowKind`、连线和生成执行器
- 旧画布缺少 `workflowKind` 时仍可加载、编辑和生成
- 剧本/分镜 JSON 解析失败时有旧文本降级展示，不丢失原内容
- 上传或生成的素材绑定真实节点 ID，删除/失败后镜头重新显示缺失
- UI 和 Agent 均不能在镜头素材缺失时生成视频
- Markdown/教程式输出不能按“每行一个镜头”降级成错误分镜表
- 未结构化原文可完整滚动查看，并可单独执行“AI 结构化原文”
- 场次和镜头结构必须通过关键字段校验后才能继续下游流程
- 格式正确但内容为英文的剧本/分镜不得直接入表，必须自动翻译并重组为简体中文
- 旧画布中曾标记为有效的英文场次/镜头在打开详情时应重新判为待中文化，且保留原文
- 素材选择器应显示缩略图、名称、类型和生成状态，绑定后仍能直接预览与更换
- 手动额外素材槽位必须参与缺失检查和后续生成依赖；解除绑定不得删除原素材节点
- 换绑后旧素材依赖线立即消失且新线出现；解绑后线立即删除，其他仍用同素材的槽位不受影响
- 分镜图绑定节点被删除、为空或已有成图时，点击分镜图按钮均不得静默无操作
- 升级前已经残留的旧图片依赖线，应在打开分镜详情时按当前绑定自动清理
- AI 返回的同名人物/道具不得重复显示；基础素材位可指定移除且不删除画布图片节点
- 分镜图必须保留全部绑定素材；PIX 1 张走 `image-edit`、2～16 张走 `multi-reference`，失败不得静默裁剪或降级
- 本地模型切换后，请求 channel ID 必须属于声明该模型的渠道，不能继续使用同能力的旧默认渠道
- 视频连接文本/剧本节点时必须先完成关键帧抽取；请求包含有序视觉帧和禁止编造契约
- 视频无法加载、解码或绘制关键帧时必须明确失败，不得退回仅凭链接/标题猜剧情
- 裁剪和分析范围不得修改原文件，且必须满足 0 <= start < end <= 原视频时长
- 视频播放、关键帧时间码和倒推输出必须使用同一绝对时间基准
- 长视频不得继续受全片 20 帧限制；必须按片段分析并保留首尾与变化证据
- 改编必须创建新分支，不能覆盖原片时间轴、原片剧本或用户上传梗概
- 双击视频节点必须直接打开专业时间线编辑器
- 缩略图、标尺、播放头、裁剪轨和分析轨必须使用同一绝对时间基准
- 拖动裁剪范围后，分析范围必须自动限制在裁剪范围内
- 逐帧、时间线缩放以及 Space、方向键、I/O 快捷键必须可用
- 预览监视器必须读取视频原始宽高比；竖屏不得被强制装入 16:9 画面
- 用户界面时间统一使用秒，内部毫秒只作为精度和存储实现，不得暴露给用户
- 剧本与分镜详情必须展示并允许编辑视觉总规范、人物一致性和场景一致性
- 人物/场景/道具素材、分镜图和视频生成提示词必须继承对应一致性设定
- 倒推和结构修复结果必须同时包含人物、场景与视觉规范；旧空数据必须能从现有场次/镜头回填
- “依据原视频/保持原风格/未指定”等泛化词不得被视为具体风格，不得进入素材生成
- 风格未具体化时必须从上游视频关键帧重新分析，并在完成前阻止人物/分镜图/视频生成
- [x] 风格重新分析期间有可见阶段、动态进度和防重复点击状态
- [x] 风格分析 Promise 失败时进度正确结束，成功写回后才显示 100%
- [x] AI 返回“无/没有/无道具”等空素材语义时不创建素材卡片和绑定
- [x] 连续镜头的视频节点真实绑定分镜首帧与共享边界尾帧，而非仅写入提示词
- [x] 场景切换镜头不强制复用上一场景的边界帧
- [x] 重新进入分镜详情可恢复已有素材和镜头产物绑定，不自动重新生成
- [x] “保存范围”和“生成裁剪视频”语义、按钮层级和产物行为清晰分离
- [x] 视频裁剪桥只监听回环地址并校验随机令牌，不接收任意文件路径
