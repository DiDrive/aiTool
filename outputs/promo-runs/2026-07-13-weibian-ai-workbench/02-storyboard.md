# 唯变AI工作台 - 10 秒竖版宣传片分镜

## 全局规格

- **成片：** 1080 x 1920，9:16，30 fps，10 秒。
- **视觉基调：** 深色发布会风格；真实产品 UI 占主画面，单一电蓝 `#2F7BFF` 用于焦点和转场。
- **素材原则：** UI 仅使用唯变AI工作台的真实录屏/截图；无真实素材时应停在素材阶段，不以生成图替代真实 UI。

### Shot 1: 从分散到聚焦 (0.0s-2.5s)

| 维度 | 描述 |
| --- | --- |
| 类型 | Hook / 痛点表达 |
| 时长 | 2.5 秒 |
| 目标 | 用一个简洁的反差，让观众意识到内容生产环节不应散落在多处。 |
| 画面 | 背景为纯深色 `#090B10`。0.0 秒出现四个细线框标签，分别为“语音”“视频”“数字人”“直播”，分散在画面四角，颜色为低对比灰。0.9 秒四个标签沿直线向画面中心收拢，合并为一个竖向的真实产品窗口轮廓；窗口尚未显示具体 UI，只显示一束电蓝色扫描线。 |
| 文字 | 0.25 秒：`内容，别再散着做。`，居中偏下，白色 60 px，字重 300。 |
| 动效 | 1. 四个标签：opacity 0 -> 1、y 20 -> 0，0.35s，`power2.out`，0.0s 开始。 2. 标签收拢：各自 x/y 向中心移动并降低 opacity，0.7s，`power3.inOut`，0.85s 开始。 3. 扫描线：scaleY 0 -> 1，0.35s，`power2.out`，1.5s 开始；随后淡出 0.2s。 4. 主文案：opacity 0 -> 1、y 24 -> 0，0.45s，`power2.out`，0.2s 开始；1.9s 起淡出。 |
| 素材 | Pack A：无。所有元素为 HTML/CSS 文本与线框；不需要 AI 图像。 |
| 转场 | 电蓝扫描线向右扩展为全屏遮罩，在 2.2-2.5 秒揭出真实软件界面。 |

### Shot 2: 一套工作台，贯通创作与播出 (2.5s-7.5s)

| 维度 | 描述 |
| --- | --- |
| 类型 | 产品登场 / 功能证明 |
| 时长 | 5.0 秒 |
| 目标 | 让观众在一个镜头内看见产品名、真实导航和数字人到直播的功能闭环。 |
| 画面 | 将真实的唯变AI工作台桌面窗口置于竖屏中心，宽度约 88%，保留应用顶部标题和左侧导航。录屏从“数字人”或“视频”页面开始，随后切到“直播”页面；切换时用蓝色 2 px 描边短暂框选左侧对应导航项。右侧不添加虚构面板。为保证竖屏可读性，真实窗口以 115% 局部裁切，重点露出左侧导航与当前页面的标题/核心操作区。 |
| 文字 | 左上角小字：`一站式AI数字人系统`，28 px，辅助灰。底部逐项出现：`数字人  ·  语音  ·  视频  ·  直播`，44 px，白色；被切到的功能词变为电蓝色。 |
| 动效 | 1. UI 窗口：scale 0.92 -> 1、opacity 0 -> 1，0.55s，`power3.out`，2.5s 开始。 2. 数字人/视频页面停留约 1.7s；导航焦点描边从左滑入，0.25s。 3. 直播页面在 4.7s 以水平 wipe 切入，0.45s，`power2.inOut`；对应“直播”文字在 5.0s 变蓝。 4. 底部功能串：每项 opacity 0 -> 1，间隔 0.18s，从 3.2s 开始。 5. 全部 UI 在 7.1s 略微缩小并压暗，为片尾留出空间。 |
| 素材 | Pack B：真实应用录屏（至少含“数字人/视频”和“直播”两段）；可从 `src/config.ts` 与当前运行应用核对品牌标题。可选：高分辨率首页截图做窗口静帧垫底。 |
| 转场 | UI 窗口向画面中心缩至 40%，同时背景加深；在 7.5 秒切到品牌锁屏。 |

### Shot 3: 品牌锁屏 (7.5s-10.0s)

| 维度 | 描述 |
| --- | --- |
| 类型 | CTA / 品牌收束 |
| 时长 | 2.5 秒 |
| 目标 | 将“唯变AI工作台”和一站式数字人定位留在观众记忆中。 |
| 画面 | 纯深色背景。Shot 2 中的真实应用窗口缩小为中央一个 340 x 520 的暗色缩略图，模糊到不可阅读，只保留真实界面的轮廓作为产品信号。其上方出现产品名，下方为一句副标题。左侧一条 4 px 电蓝竖线从下方长出，和产品名基线对齐。 |
| 文字 | `唯变AI工作台`，居中，72 px，白色，字重 400。下方：`一站式AI数字人系统`，32 px，`#AAB3C2`。最底部小字：`生成内容，开始直播。`，26 px，白色 80% 不透明度。 |
| 动效 | 1. 产品名：opacity 0 -> 1、y 18 -> 0，0.45s，`power2.out`，7.65s 开始。 2. 蓝色竖线：scaleY 0 -> 1，0.35s，`power2.out`，7.7s 开始。 3. 副标题：opacity 0 -> 1，0.35s，8.15s 开始。 4. 底部文案：opacity 0 -> 1，0.3s，8.55s 开始。 5. 9.6-10.0 秒整体保持静止，不做突然淡黑，方便平台截帧。 |
| 素材 | Pack B：Shot 2 录屏截取的真实 UI 缩略图；应用 logo 可从项目现有 `/logo.svg` 导出（可选）。 |
| 音效 | 7.5 秒一个干净的低频落点；7.9 秒加入轻微提示音。若有配音，最后一句“唯变AI工作台，一站完成。”在 7.7-9.3 秒落下。 |

## HyperFrames 实现提示

```text
建立一个 1080x1920 的单根 composition，时长 10 秒，30 fps。
使用 #090B10 深色背景，白色无衬线中文字体与唯一强调色 #2F7BFF。
Shot 1 仅用可访问的文本和 CSS 线框表达四个功能收拢；Shot 2 以真实唯变AI工作台录屏为主，裁切出左侧导航和当前功能页，禁止用 AI 生成伪 UI；Shot 3 由真实 UI 的暗色缩略图与文字品牌锁屏收束。
所有动画使用克制的 opacity、transform、clip-path 和 2px 描边，不使用粒子、霓虹光球、假数据、夸张 3D 或多色渐变。
```

## 下一阶段前的确认点

2. 确认 9:16 竖版投放；若用于官网或发布会，需改为 16:9 并重新裁切 Shot 2。
3. 提供或录制真实 UI 素材后，才能进入素材计划与剪辑阶段。
